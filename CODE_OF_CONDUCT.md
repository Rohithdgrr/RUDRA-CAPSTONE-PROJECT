# Code of Conduct

> Adapted from Contributor Covenant 2.1

## Pledge

We pledge to make participation harassment-free for everyone, regardless of background.

## Standards

- Be respectful, constructive, empathetic.
- No harassment, discrimination, trolling, or unwelcome conduct.
- Focus on technical merit.

## Enforcement

Report to maintainers via GitHub issue or `conduct@renode-resilience.local` (placeholder). All reports confidential; enforcement may include warning/ban.

## Scope

Applies in repo, issues, PRs, and related community spaces.
